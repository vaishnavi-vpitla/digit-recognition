# Handwritten Digit Recognition 
A web application built with Streamlit and a Convolutional Neural Network (CNN) trained on the MNIST dataset to recognize handwritten digits in real time.
## Features 
-Interactive drawing canvas where users can draw digits from 0 to 9.
-Instand prediction powered by a custom-trained Keras model.
-Displays both the predicted digit and confidence percentage.
